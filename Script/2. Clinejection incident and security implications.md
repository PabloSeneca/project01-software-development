In the Clinejection case, malicious instructions in a GitHub issue could trick an AI bot into running commands. Combined with weaknesses in the build system, this created a path to credentials used to publish software.

Cline removed the vulnerable workflows on February ninth, 2026. However, one exposed publishing token remained active. On February seventeenth, an attacker used it to publish an unauthorized Cline command-line package that installed OpenClaw.

Cline reported no stolen user data or malicious code delivered. Still, someone outside the team had gained control over a software release.

The security lesson is that untrusted input, powerful tools, and weak access boundaries can put the software distribution process at risk.
