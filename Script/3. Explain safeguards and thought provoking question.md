How do we defend our systems while still enjoying the productivity of agents? We implement four concrete safeguards. 
First, principle of least privilege: give agents only the tools and filesystem access strictly needed.
Second, isolate environments so publishing secrets never touch agent execution loops.
Third, verify revocation: if a credential might be exposed, invalidate and test it immediately.
Fourth, require explicit human sign-off on critical operations like deploying or publishing packages.

To conclude our presentation, we want to leave the class with this fundamental design question: As a software engineer, where should we draw the line? What actions should an AI agent handle entirely on its own -- like formatting code or drafting tests -- and where must a human strictly step in to review and authorize?
